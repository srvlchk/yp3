Цель проекта: создать виртуальный прототип "Умный офис". В серверной при повышении температуры автоматически включается охлаждение, а сотрудник со своего места следит за оборудованием и может управлять вентилятором. Датчики и вентилятор имитируются в NODE-Red, сеть собирается в GNS3.
номер в журнале 23
Роли устройств:
WIN - Windows Server 2019, рабочее место администратора.
CTRL - управляющий узел (логика управления вентилятором)
MON - мониторинг состояния оборудования 
DB - база данных SQlite
IOT - NODE-Red: модели датчиков и вентилятора
